# VaaniAI

VaaniAI is a voice-first conversational AI assistant built on a FastAPI backend. It accepts speech input directly from the browser, processes it through a local speech-to-text pipeline, reasons over it using an LLM agent equipped with real-time tools, and returns a spoken audio response generated by a local TTS engine.

The assistant can answer general questions, search the web, fetch live weather data, and answer questions grounded in PDF documents you upload — all through a single browser-based interface.

## Core Capabilities

**Speech Recognition (STT)**  
Audio recorded in the browser is sent to the server and transcribed using the OpenAI Whisper API (`whisper-1`). The language is fixed to English by default.

**Conversational AI Agent**  
The `VaaniAI` agent is built on a custom agentic loop backed by the OpenAI API (default model: `gpt-4.1-mini`). The agent maintains per-session conversation history and decides autonomously when to invoke tools before generating a final response.

**Tool Execution**  
The agent has access to three tools:

- **Web Search** — queries the Tavily API for real-time web results
- **Weather** — queries the OpenWeatherMap API for current weather conditions
- **PDF Search** — performs a hybrid (vector + full-text) search against the active uploaded document

**Document Ingestion and RAG**  
PDFs uploaded through the UI are chunked, embedded locally using the `all-mpnet-base-v2` SentenceTransformer model (768-dimensional embeddings), and persisted in a PostgreSQL database with the `pgvector` extension. Documents are identified by their SHA-256 content hash, so re-uploading an identical file skips re-embedding entirely.

**Text-to-Speech (TTS)**  
The agent's text response is synthesized into speech using Piper TTS, a local neural TTS engine. The binary and voice model (`en_US-lessac-medium`) are downloaded automatically on first run. The generated `.wav` file is served back to the browser for playback.

**Web Interface**  
The frontend is a single-page HTML/CSS/JS application served as static files by FastAPI. It uses the browser's native `MediaRecorder` API to capture microphone input and communicates with the backend via standard fetch calls.
