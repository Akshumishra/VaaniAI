# VaaniAI

VaaniAI is a voice-first conversational AI assistant built on a FastAPI backend. It accepts speech input directly from the browser, processes it through a local speech-to-text pipeline, reasons over it using an LLM agent equipped with real-time tools, and returns a spoken audio response generated by a local TTS engine.

The assistant can answer general questions, search the web, fetch live weather data, and answer questions grounded in PDF documents you upload — all through a single browser-based interface.

## Quick Start / How to Run Locally

### Prerequisites

- Python 3.14 or newer
- PostgreSQL with the `pgvector` extension installed
- A Hugging Face account (needed to download the Piper TTS voice model on first run)
- `uv` installed for dependency management

### 1. Clone the repository

```bash
git clone https://github.com/Akshumishra/VaaniAI.git
cd VaaniAI
```

### 2. Install dependencies

Use `uv` to create a virtual environment and install all packages:

```bash
uv sync
```

Activate the environment:

```bash
# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

### 3. Configure environment variables

Copy `.env.sample` to `.env` and fill in your values:

```bash
cp .env.sample .env
```

You will need to set:
- `OPENAI_API_KEY` (Required for transcription and LLM)
- `DATABASE_URL` (Defaults to `postgresql://postgres:postgres@localhost:5432/postgres`)
- `HF_TOKEN` (Required for the first run to download the TTS voice model)
- `TAVILY_API_KEY` (Required for Web Search functionality)
- `WEATHERAPI_KEY` (Required for Weather functionality)

### 4. Database Setup

Ensure your PostgreSQL instance is running and the `pgvector` extension is created. The application will automatically create the required `document_chunks` table on startup.

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

### 5. Run the application

Start the FastAPI development server:

```bash
uvicorn src.backend.api.main:app --reload
```

Open your browser and navigate to:

```
http://localhost:8000
```

*(Note: On the first startup, the server will download the necessary TTS binaries and models, which may take a minute.)*
